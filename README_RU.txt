ArtyomX64 — Notes cursor + mkdir / Finder New Folder

Содержимое:
- main.elf — пересобранное ядро с системным вызовом mkdir (номер 83, int 0x80).
- initrd.img — пересобранный initrd с обновлёнными Notes и Finder/Files.
- apps/notes.c, apps/files.c — исходники приложений.
- apps/notes.bin, apps/files.bin — собранные GUI-приложения.
- fs/, lib/ — исходники VFS, FAT/EXT и системного вызова mkdir.
- ArtyomX64_mkdir_notes.patch — diff исходников относительно исходного дерева.

Notes:
- ← / → — перемещение курсора по символам.
- ↑ / ↓ — перемещение по визуальным строкам, с сохранением колонки.
- Home / End — начало / конец логической строки.
- Ввод и Backspace редактируют текст в позиции курсора, а не только в конце.
- Автопрокрутка удерживает курсор в видимой области; View menu по-прежнему листает документ.

Finder:
- File > New Folder... открывает поле ввода имени.
- Enter создаёт каталог, Esc отменяет; после успеха список обновляется.

mkdir:
- Пользовательский интерфейс: mkdir(path, mode), syscall 83 через int 0x80.
- initrd: каталоги создаются в RAM; они не переживают перезагрузку.
- FAT12/16/32: реализовано создание каталогов, включая записи '.' и '..'.
- EXT: добавлена базовая реализация mkdir через текущий EXT write-слой; использовать только на томах, которые автомонтирование разрешает изменять. EXT4 metadata checksums и особенности конкретных томов требуют отдельного runtime-тестирования.
- NTFS и любые тома, помеченные read-only, возвращают ошибку; успешное создание не имитируется.
- Пути поддерживают префиксы initrd/ и diskN/; для дисковых каталогов родительский каталог должен существовать.

Сборка:
- `make -j2` — ядро и WindowServer.
- `make -C apps notes.bin files.bin` — приложения.
- `make -C apps initrd` — обновить initrd.

Проверка в этой среде:
- Полная сборка `make -j2` прошла успешно.
- Notes и Files собраны успешно.
- initrd.img пересобран успешно.
- Runtime-проверка в QEMU/на реальном оборудовании не выполнялась; особенно важно протестировать mkdir на тестовом FAT и EXT-образе, а не на единственной копии важных данных.
