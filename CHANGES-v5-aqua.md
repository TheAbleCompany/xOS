# CHANGES -- r13 / WindowServer v5 "Aqua edition"

## Обзор

Рефакторинг архитектуры GUI завершён: единый дизайн-стек Mac OS X Lion
(Aqua) перенесён в userspace WindowServer-модель, как в MacOS X.

Слоёный пирог теперь такой (все уровни -- userspace, ядро GUI не касается):

    libax.h      сисколлы портов + канвас          (аналог DPS-слоя)
    axquartz.h   2D-примитивы                      (аналог Quartz 2D)
    axaqua.h     виджеты + дизайн-токены           (аналог Cocoa/Aqua)
    wserver.bin  WindowServer: композитор + хром   (аналог WindowServer)

Палитра хрома сервера (LION_* в server/wserver_internal.h) и палитра
виджетов приложений (AQ_* в lib/axaqua.h) зеркалят друг друга, поэтому
окно приложения выглядит бесшовным продолжением композитора.

## lib/ -- клиентские библиотеки

- НОВЫЙ lib/axquartz.h: header-only AxQuartz ("Quartz 2D") -- blend/lerp/
  tint/shade, alpha-пиксели, скруглённые прямоугольники (fill/outline/
  gradient), вертикальные/горизонтальные градиенты (в т.ч. с альфой),
  AA-круги и gloss-кружки traffic lights, soft shadow, gloss-top,
  hairline, глифы, масштабируемый текст, blit. Рисует в канвас окна
  (g_canvas/g_cw/g_ch из libax), всё клипуется, integer-only, без FPU.
- НОВЫЙ lib/axaqua.h: AquaKit ("Cocoa") -- дизайн-токены (окно,
  toolbar, accent, кнопки, поля, sidebar, scrollbar, терминальная
  палитра) и виджеты: aq_button (normal/default/disclusure x
  up/hover/down/disabled), aq_field, aq_sidebar (+items/captions),
  aq_scrollbar, aq_select_rect/aq_hover_rect, aq_panel, aq_checkbox,
  aq_progress, aq_slider, aq_segments, процедурные иконки (terminal,
  folder, notes, calc, gl, prefs, about, doc, exec).
- Сигнатуры libax не менялись -- старые приложения совместимы.

## server/ -- WindowServer (wserver.bin, AX_VERSION -> "3.0 Aqua")

- wserver_gfx.c/.h: добавлены Lion-примитивы, побайтово те же
  алгоритмы, что в axquartz.h: gfx_vgradient_alpha,
  gfx_rounded_vgradient(+_alpha), gfx_gloss_circle, gfx_circle_aa,
  gfx_soft_shadow, gfx_gloss_top, gfx_glyph.
- wserver_internal.h: палитра LION_* (menubar/menus/titlebar/traffic
  lights/dock), AX_WALL_SPACE, AX_ABOUT_W/H, геометрия traffic lights
  AX_BTN_R/C1/C2/C3, виды анимаций AX_ANIM_*(OPEN/MINI/RESTR) +
  поля anim_kind/anim_t в ax_surface_win.
- wserver_surface.c: окна в стиле Lion -- brushed-metal титлбар с
  центрированным заголовком (тёмный текст + 1px emboss), Aqua
  traffic lights (точные круги с AA-юбкой, серые когда окно не в
  фокусе, цветные + глифы x/-/+ при наведении), 1px рамка
  LION_FRAME_EDGE, hairline под титлбаром, soft shadow вместо
  прямоугольной тени. Анимации: zoom-open при создании окна,
  genie-to-dock при минимизации (жёлтая кнопка и Hide <App>),
  обратный genie при восстановлении из дока.
- wserver_ui.c: полный Lion-редизайн:
  * меню-бар: размытие обоев под панелью + полупрозрачный светлый
    градиент, бейдж-кнопка логотипа (подсвечивается акцентом),
    динамическое имя приложения жирным (1px double-draw), квадратные
    белые drop-down панели с hairline-бортиком, подсветка пунктов
    акцентом, справа дата + часы + глиф батареи с процентом;
  * dock: стеклянная полка-«стол» в перспективе (задний край уже,
    стороны расходятся), размытие обоев сквозь стекло, большие
    иконки (52px), стоящие на полке, магнификация вокруг курсора
    с расталкиванием соседей, точки запущенных приложений, чёрный
    tooltip над иконкой; клик по запущенному приложению фокусирует
    его окно вместо запуска второй копии;
  * виджеты: глянцевые тёмные часы со стеклянным куполом, светлый
    календарь-карточка с красной шапкой iCal-стиля, светлая стеклянная
    карточка System Monitor;
  * курсор: чёрная Lion-стрелка с белой обводкой;
  * контекстное меню: Lion-панель (Space/Gradient/Photo/Slideshow
    обои, Next Accent, About);
  * About: brushed-metal панель "About This System" 380x236 с тёмным
    бейджем системы.
- wserver_input.c: клики traffic lights по Lion-геометрии
  (центры 19/39/59, зона R+2), жёлтая кнопка запускает genie,
  клик по About-диалогу в новых границах.
- wserver_launch.c: app_is_running() (индикаторы дока), restore
  из дока проигрывает genie в обратную сторону.
- wserver_wallpaper.c: процедурные обои "Andromeda" (AX_WALL_SPACE,
  режим по умолчанию): трёхполосный градиент deep-space, туманности
  (мягкие радиальные свечения), 360 звёзд по детерминированной LCG-
  таблице, сгущённые к диагональной «млечной» полосе, свечение
  горизонта. Кэшируется в один буфер и блитится построчно.
- wserver_menu.c: без изменений логики (реестр меню приложений).

## apps/ -- приложения на AquaKit

- calc.c, prefs.c: перерисованы на axquartz+axaqua (единый дизайн).
- files.c, notes.c: портированы из lion-дерева -- это AquaKit-
  приложения; в r12 их исходников не было (в initrd лежали старые
  бинарники). Меню регистрируют через ax_menu_set (модель macOS:
  меню приложения рендерит сервер, клики приходят как AX_EV_MENU).
- Сборка: обычные CFLAGS (-mno-sse), линковка с libc.o -- без изменений.

## Сборка и артефакты

- wserver.bin: server/Makefile (freestanding, -nostdlib, PIE, no-SSE),
  размер ~94.6 KB.
- initrd.img: repack (scripts/repack_initrd.py -- теперь заменяет и
  wserver, и calc/prefs/files/notes), 56 файлов, ~4.98 MB.
- main.iso: scripts/build_iso.py (Limine BIOS+UEFI гибрид,
  El Torito + MBR stage1/2 + EFI-партиция), ~9.5 MB.
- ЯДРО НЕ МЕНЯЛОСЬ: main.elf -- тот же r12-bootfix (все фиксы
  переносимости загрузки сохранены).

## Проверки

- gcc -Wall -Wextra: 0 ошибок у wserver и всех 4 приложений
  (только старые -Wsign-compare в wserver_gfx.c).
- nm --undefined-only: пусто у всех 5 бинарников.
- В ISO присутствуют новые wserver.bin и calc.bin (побайтовая
  сверка первых 4KB).
- Сигнатуры клиентского API не менялись -- term/xsh/temu/guitest/
  raycaster/cube/hovertank собираются и работают как раньше.

## Известные ограничения

- Разрешение канваса при композитинге масштабируется в рамку
  (fw-4 x fh-tbh-2) -- как в lion-референсе: канвас приложения
  чуть сжимается по ширине на 4px. Приложения рисуют с запасом.
- Resize grip линии убраны (Lion-стиль), угловое изменение размера
  по-прежнему работает (зона не изменилась).
- File/Edit/View fallback остаются для приложений без своих меню.

## r14 -- перенос деталей Lion CSS3-реконструкции из kernel-AXShell в WindowServer v5

Дизайн, выработанный в kernel-версии AXShell за 7 раундов правок
(перспектива дока, квадратные меню, точные значения из CSS3-реконструкции
Lion Alessio Atzeni), перенесён 1-в-1 в userspace WindowServer.
Ядро не менялось. Файлы: wserver_internal.h, wserver_surface.c,
wserver_ui.c (+ харнесс-хуки HOST_HARNESS в wserver_gfx.c /
wserver_surface.c / wserver_menu.c / wserver_wallpaper.c).

### Окна (wserver_surface.c)

- Тайтлбар -- точные градиенты реконструкции: активное #E9E9E9 ->
  #B2B2B2, неактивное #E8EEF0 -> #D6D6DC; заголовок #3C3C3C с
  эмбоссом #E7E7E7 (было: светлый градиент 246/218 и белая тень).
- Светофоры -- градиенты демо (#FD4E4E / #F3BB55 / #96D16F с тёмными
  кромками), поверх каждого -- белый глянцевый купол (':after' демо,
  43% высоты), под кнопками 1px белая кромка rgba(255,255,255,.5).
- Рамка окна rgba(0,0,0,.3) (было 0x66,40,40,48); hairline под
  тайтлбаром #656565; двойная глубокая тень 0 22px 70px rgba(0,0,0,.56)
  (два прохода gfx_soft_shadow 14/5 и 22/3).

### Док (wserver_ui.c)

- Ступенчатая магнификация демо вместо плавной: hovered x2.67
  (139px), соседи x2 (104), +-2 x1.5 (78), остальные x1; hovered
  выбирается по RESTING-центрам (стабильные бакеты без осцилляций),
  размеры едут к цели /4 за кадр (~0.15s), ряд рефлоуится на полный
  рост (inline-block демо); зоны ховера/клика расширены до ~139px.
- Отражения иконок (-webkit-box-reflect): 12 зеркальных строк под
  иконкой с затуханием 0x48 -> 0; иконки подняты на 12px от низа
  полки.
- Индикаторные точки .fresh: белое ядро + циановое свечение
  rgb(75,255,255) (r5 0x30 / r3 0x66 / r2 0xE0).
- Тултип демо: чёрный rgba(0,0,0,.6), радиус 8, 6px стрелка вниз,
  позиционируется над верхом иконки.
- Bounce при запуске (.bounce): 4 синус-цикла, 16 кадров
  (gfx_sin_deg(t*90) * 10 / 256); включается в dock_click при
  запуске приложения и About.

### Меню (wserver_ui.c)

- Панели rgba(255,255,255,.95) с рамкой rgba(0,0,0,.19), тень
  0 6px 12px .7 (было: сероватый градиент 252/242 и тень r3).
- Подсветка пунктов И открытых заголовков -- синий градиент демо
  #7793F5 -> #406DF2 -> #275AF1 с кромкой #1746D7 (новая
  draw_blue_highlight(); акцентный цвет остался для виджетов

### Хост-харнесс (scripts/host_harness_ws5)

- Сборка реальных файлов сервера (wserver_gfx/ui/surface/wallpaper/
  menu) на Linux: сисколл-обвязки под HOST_HARNESS заменены
  стабами (порты/SHM/task_alive/exec), gfx_init -- хуком

### Сборка

- initrd.img (формат mkinitrd2: u32 count, 76-байтные записи

## r16 -- зеркальный док (отражения + огоньки) и градиентные меню

### Док -- отражения и индикаторные огоньки

- Иконки снова СТОЯТ на стекле с полосой 12px под ними
  (iy = sy + sh - 12 - sz): их зеркало отчёрчивается в стекле --
  12 зеркальных строк с затуханием 0x48 -> 0, как в monolithic.
  Читается построчно из только что отрисованной иконки
  (gfx_get_pixel), смешивается с стеклом через gfx_blend и
  пишется предвычисленным значением (gfx_pixel с уже
  смешанным цветом -- альфа-слепая запись сырого ARGB не
  используется).
- Индикатор запущенного приложения снова ОГОНЁК: белое ядро
  r2 (0xE0) + циановое свечение r3 (0x66) и r5 (0x30),
  rgb(75,255,255) -- вместо тёмной точки r2 из r15. Горит у
  любого живого окна приложения, ВКЛЮЧАЯ свёрнутое
  (app_is_running сканирует все surfaces с used=1).
- Огонёк отражается в стекле: под ним 3 затухающие строки
  0x38/0x24/0x14 (120,255,255), сужающиеся 7/5/3 px.
- Магнификация, клик-полосы, тултип r5, трапеция-перспектива
  (DOCK_PERSP 8, острые углы) -- без изменений (r15).

### Меню -- градиент возвращён

- Подсветка выбранного пункта снова СИНЕЙ ВЕРТИКАЛЬНЫЙ
  ГРАДИЕНТ из реконструкции: #7793F5 -> #406DF2 (50%) ->
  #275AF1 с кромкой #1746D7 (новая draw_blue_highlight();
  портирована из kernel-раунда 7/8). Плоская accent_alpha

- Градиент применён ко ВСЕМ меню: пункты логотип-меню,
  приложений и контекстного меню + ОТКРЫТЫЕ заголовки
  меню-бара. Hover заголовка до открытия -- прежний тёмный
  0x46 (как в kernel).
- Панели остались «слегка серыми» полупрозрачными с
  вертикальным градиентом (просьба r15), квадратность
