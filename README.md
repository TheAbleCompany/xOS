
# Структура проекта
## Точка входа:
	Файл kernel/main.c
	Папка boot
### Функции стандартной бибилиотеки и реализация системных вызовов (папка lib):
	common.c - отвечает за функции портов ввода/вывода и реализации некоторых функций ### стандартной библиотеки C
	syscalls.c - собственно сами системные вызовы.
## Реализация собственной файловой системы UNIX (папка fs):
	fs.c
	initrd.c
## Реализация драйверов и обработки прерываний:
### Папка drivers:
	monitor.c - отвечает за вывод текстовой информации на экран (драйвер монитора)
	keyboard.c - драйвер клавиатуры (пока поддерживает только строчные буквы)
	keyboard_map.h - карта вводимых с клавиатуры символов
### Папка kernel:
	descriptor_tables.c - массив ссылок на обработчики прерываний
	isr.c - реализация обработки некоторых прерываний: программных (системные вызовы) и аппартных (клавиатура)
	interrupt.asm - вызывает обработку прерываний и сбор аргументов с регистров.
### Реализация загрузчика исполняемых файлов и менеджера памяти:
	fs/loader.c
	mm/malloc.c

## Архитектура GUI: WindowServer (NeXTSTEP / MacOS X model)

GUI живёт в ОТДЕЛЬНОМ процессе (аналог WindowServer):

    ядро (kernel/)          -- только примитивы: порты сообщений
                               (kernel/ipc.c, сисколлы 178-195),
                               задачи, FS, драйверы. Никакого GUI.
    server/wserver*.c       -- WindowServer: композитор, окна,
                               док, меню, обои, ввод, запуск
                               приложений. Собирается в
                               wserver.bin (userspace ELF).
    apps/*                  -- клиенты: рисуют в канвасы (SHM),
                               общаются с сервером через порт
                               "wserver" (lib/libax.h).

Загрузка: ядро делает exec("wserver") из initrd; сервер
создаёт порт "wserver" и дальше всё общение -- сообщения
(Mach-подобная модель). Подробности: CHANGES-windowserver.md.

### Mac OS X Lion Edition (r14)

    F4  / иконка-ракета в доке  -- Launchpad: полноэкранная сетка
                                   приложений, запуск по клику, фон
                                   с "дорогим" блюром (downscale +
                                   upscale + blur), кэш в SHM
    F3                          -- Mission Control: все окна
                                   (включая свёрнутые) сеткой
                                   миниатюр, клик = фокус + genie-
                                   восстановление из дока
    F11 / зелёный светофор      -- полноэкранный режим окна (меню-бар
                                   и док прячутся; курсор у верхнего
                                   края возвращает меню-бар)
    Esc                         -- закрыть оверлей
    двойной клик по тайтлбару   -- zoom (maximize)

Системные клавиши работают без фокуса (перехват в
server/wserver_input.c до доставки приложению).  Отрисовка окон
идёт по z-order (сфокусированное окно всегда сверху).  Детали и
история: CHANGES-windowserver.md.

Хост-харнесс (кадры GUI без QEMU, для отладки): tools/lion_harness.c
(см. команды сборки в CHANGES-windowserver.md).

Сборка:
    make                    -- ядро + WindowServer
    make -C apps all        -- приложения
    make -C apps initrd     -- initrd (включая wserver и quake)
    make limine-iso         -- ISO
